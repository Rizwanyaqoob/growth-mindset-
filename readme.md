# 🌱 Growth Mindset Challenge - Streamlit App

Welcome! This project is part of the **Growth Mindset Challenge**, where we explore how adopting a growth mindset can improve learning, performance, and motivation.

## 🚀 About the App

This Streamlit web app explains what a growth mindset is and how you can practice it. It is built using Python and Streamlit, and hosted online.

🔗 **Live App:** [Click here to open the app](https://your-username-your-app.streamlit.app)  
📌 **Note:** Source code is intentionally **not shared** publicly as per the challenge instructions.

## 📚 What is a Growth Mindset?

A **growth mindset** is the belief that your abilities and intelligence can be developed through effort, learning, and persistence.

This app covers:
- What a growth mindset is
- Why it’s important
- How to develop one
